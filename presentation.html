RAG PIPELINE WORKFLOW Data Transformation & Context Injection

How Information Moves Through RAG

1. Multi-Source Ingestion:

Documents (PDF/DOCX/TXT) and flowchart diagrams are parsed and tokenized.

2. 768-D Vector Embeddings:

nomic-embed-text converts semantic chunks into dense vector coordinates.

3. ChromaDB Cosine Indexing:

Stored in HNSW vector graph space for sub-20ms neighbor retrieval.

4. Grounded Context Generation:

Top-3 relevant chunks are retrieved and injected into the LLM context prompt.

Embeddings: nomic-embed-text (768-D) Vector Search: HNSW Cosine (< 20ms) LLM: Qwen2.5-VL / LLaMA 3.1 8B

RETRIEVAL PIPELINE Dense Vector + BM25 Lexical + RRF Ranking
Dual-Path Retrieval Architecture
Path A: ChromaDB Dense Vector Search (Top 15)

Embeds query with nomic-embed-text. Catches synonyms, paraphrasing, and semantic intent.

Path B: BM25 Lexical Search (Top 15)

In-memory keyword index. Essential for exact form IDs (Form 402) and extensions (ext. 4357).

Reciprocal Rank Fusion (RRF, k=60)

Score(d) = Σ [ 1 / (60 + rank_vector) + 1 / (60 + rank_bm25) ]

Query Execution Flow & Confidence Gate
1 Query Expansion: "PTO" → "Paid Time Off Leave"
2 Parallel Search: Vector Top-15 ⇄ BM25 Top-15
3 RRF Fusion: Merges into unified Top-10 candidates
4 Cross-Encoder Rerank: ms-marco-MiniLM Top-3
5 Confidence Gate: If Score < 0.45, return fallback in <300ms
Retrieval Latency: ~0.38s Recall @ 3: 98.6% Fallback Bypass: < 0.3s

You are an internal assistant for Acme Enterprise.
You are an EXTRACTOR, not an author.

RULES:
1. Extract facts strictly from SOP context.
   Never add outside knowledge or assumptions.
2. Use numbered steps for procedures, bullets for rules.
3. Terminate answer with exact citation:
   Source: <filename> (Section: <heading>)
4. If context has no answer, reply ONLY with fallback.
5. No greetings, no pleasantries, no conclusions.
Inference Hyperparameters: Temperature: 0.2 • Top_P: 0.9 • Max Tokens: 512
Confidence Gate & Fallback Engine
Confidence Calculation:

Score = 1.0 − BestCosineDistance(Top3Chunks)

Threshold Cutoff (0.45):

If Score < 0.45, query is flagged as out-of-scope enterprise query.

Zero-Compute Fallback Bypass:
Responds in < 300ms without calling LLM: "This isn't covered in our SOPs — please contact the concerned department."
Prevents costly GPU compute & eliminates hallucination completely.
